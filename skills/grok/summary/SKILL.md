# Summary

When the user inputs /summary:

- Summarize every question the user has asked during the conversation.
- Extract and list the main takeaways, conclusions, important facts, and outcomes discussed so far.
- Structure it clearly with bullet points for easy reading.
- Stay neutral and factual.
